ENGINEERING ARCHITECTURE

Built with Rust for zero-overhead chaos.

Manipulate OSI Layer 3/4 packets without intermediate proxy hops or TLS certificate MITM overhead.

KERNEL DRIVER

WinDivert Kernel Packet Interception

Hooks directly into the Windows network stack via kernel-level WinDivert drivers. Intercepts raw IPv4/IPv6 TCP, UDP, and ICMP frames before socket buffering occurs.

ASYNC EVENT LOOP

Tokio Channel Queues

Zero-cost asynchronous channel buffers hold delayed packets in user space without blocking OS threads or thread pool exhaustion.

TUI DASHBOARD

Ratatui Real-Time ASCII Terminal

Live terminal user interface with real-time throughput gauges, packet drop graphs, and hotkey switching right in your CLI.

TARGETING & PID SANDBOX

Multi-Port & Process Traffic Sandboxing

Target individual development ports (e.g. 3000, 8080, 5000) or specific process IDs so you can stress test your staging app while keeping Discord, Spotify, and Slack running smoothly.

PROBABILISTIC LOSS

Bernoulli & Burst Loss

Simulates both independent random drop rates and realistic temporal burst packet loss modeling intermittent radio drops.

STANDALONE BINARY

< 5MB Native Binary

GETTING STARTED

Install in seconds.

Start testing your app against chaotic network degradation right away.

BASH / POWERSHELL 
# Install directly via cargo from source
cargo install --git https://github.com/bhavukar/network-relay.git

# Start simulating spotty subway network on port 3000 (Run as Admin)
subway-sim start --port 3000 --profile subway
STANDALONE EXECUTABLE 
# Clone and build optimized release binary
git clone https://github.com/bhavukar/network-relay.git
cd network-relay
cargo build --release

# Run subway-sim
.\target\release\subway-sim.exe start --port 8080 --profile elevator
CLI FLAGS 
# Fine-tune exact latency and drop rate values
subway-sim start --port 8080 --latency 1500 --drop 15

# Options:
--port <PORT>       Target specific port (default: 8080)
--profile <NAME>    subway | elevator | mountain | 3g
--latency <MS>      Custom latency delay in milliseconds
--drop <PERCENT>    Custom packet drop percentage (0-100)
