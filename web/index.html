CORE PLATFORM CAPABILITIES

Built for zero-overhead kernel network manipulation.

01 // KERNEL DRIVER

WinDivert Interception

Hooks directly into the OS network stack via low-level WinDivert kernel drivers. Intercepts raw IPv4/IPv6 TCP, UDP, and ICMP frames before socket buffering occurs.

02 // ASYNC EVENT LOOP

Tokio Delay Queues

Asynchronous channel buffers hold delayed packets in user space without thread blocking or OS context-switch overhead, handling up to 100k packets per second.

03 // PROCESS SANDBOXING

Target Port Filtering

Target specific local ports (e.g. 3000, 8080, 5000) or individual process IDs so you can stress test your staging service without degrading Spotify or Slack.

GETTING STARTED IN SECONDS

Simple CLI installation. Zero config required.

QUICKSTART INSTALLATION 
# 1. Install directly with Rust / Cargo
cargo install --git https://github.com/bhavukar/network-relay.git

# 2. Start simulating spotty subway network on port 3000 (Run as Administrator)
subway-sim start --port 3000 --profile subway

# 3. Or pass custom latency and packet drop rates directly
subway-sim start --port 8080 --latency 1500 --drop 15
